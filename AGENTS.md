# User preferences

## Git and publishing

The user prefers to commit and push changes themselves. Prepare and verify the
requested changes, then leave them in the working tree for the user.

Do not commit, push, open a pull request, merge, or deploy unless the user
explicitly asks the assistant to perform that action. Statements such as
"I want to push this" or "I'm going to push" describe the user's next step;
they are not permission for the assistant to push.

When handing work back, briefly report the changes, validation results, and any
remaining steps. Do not add an unsolicited approval flow.
